# V51 — Importar PDF después de la página visible

Corrige el bloqueo de V50 al regresar del selector de PDF. PDF y calibración usaban el código Android `504`; la respuesta entraba por calibración y se descartaba, dejando la importación ocupada. PDF usa ahora `508`, separado de guardar, imágenes, carpeta, calibración y cuadernos. Cancelar, rechazar una solicitud ocupada o fallar la lectura devuelve el control del editor. Una prueba de Android recorre el despachador real y comprueba esos caminos y la ausencia de códigos duplicados.

El botón lleva un icono de documento con esquina doblada y signo de añadir. Su descripción indica **Insertar PDF después de la página visible**.

La página destino se captura al tocar el botón. Las páginas del PDF se intercalan justo después, incluso si la hoja termina a mitad de un párrafo de lista o entre filas de una tabla. No se reemplaza el texto seleccionado, no se corta su párrafo y no se repite la marca de lista. El motor conserva exactamente la geometría del contenido existente, desplazando su número de página cuando corresponde. Los bloques de PDF del editor indican su hoja de destino y permiten verla o eliminarla.

Insertar o eliminar páginas desplaza las referencias de otros PDF y las imágenes posteriores. El historial conserva esos movimientos y el borrador conserva las posiciones. Los PDF permanecen vinculados a su posición de página; editar el texto no convierte el PDF en parte de un párrafo.

Una composición anterior se cancela antes de abrir el selector para que no retrase la importación. Al terminar, se solicita inmediatamente la nueva previsualización y se muestra la primera página insertada, también en notas largas o con vista automática desactivada. Cambiar las inserciones invalida la caché anterior; posteriores cambios de texto siguen pudiendo reutilizar el prefijo ya compuesto.

Pruebas añadidas: selección/cancelación/reintento de PDF, rechazo nativo, importación durante una composición larga, inserción entre páginas de PDF, desplazamiento de imágenes, deshacer/borrador, lista partida entre hojas, tabla de varias páginas, posiciones posteriores al texto, equivalencia de caché y límites. El rasterizador PDF real y la apertura en Huawei Notes siguen necesitando comprobación en la tablet.
